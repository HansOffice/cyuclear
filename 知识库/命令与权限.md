# CyuClear 命令与权限

## 命令概览

- 主命令：`/cyuclear`
- 别名：`/cc`
- 命令格式：`/cc <子命令> [参数...]`

在聊天框键入 `/cc help` 可唤出可点击翻页的帮助列表；所有管理命令均支持 Tab 智能补全

## 玩家命令

| 命令 | 权限 | 说明 |
|---|---|---|
| `/cc bin` | `cyuclear.use` | 打开虚空垃圾桶界面，拾回刚被清理的掉落物 |
| `/cc help [页码]` | `cyuclear.use` | 查看当前可用的命令帮助列表 |

## 管理员命令

以下命令均需要 `cyuclear.admin` 权限或拥有管理员身份（OP）：

### 核心清理与检查

| 命令 | 说明 |
|---|---|
| `/cc items` | 立即执行一次掉落物清理 |
| `/cc entities` | 立即执行一次实体清理 |
| `/cc all` | 立即同时执行掉落物与实体清理 |
| `/cc here [items\|entities\|all]` | 仅清理当前玩家脚下所在区块的掉落物或实体 |
| `/cc check` | 检查准星瞄准的掉落物、实体或方块的清理规则判定 |
| `/cc preview` | 预演一次清理流程，输出预计扫描与清理数据，不实际删除任何物品 |
| `/cc cancel` | 紧急中断当前正在执行的分批清理扫描任务 |

### 恢复与运行批次

| 命令 | 说明 |
|---|---|
| `/cc runs [页码]` | 列出近期的清理批次记录 |
| `/cc run <批次ID> [details\|reasons]` | 查看指定清理批次的详细耗时、扫描数或实体清理原因明细 |
| `/cc recover <批次ID>` | 撤销并恢复指定清理批次中的物品或生物 |

### 系统监控与热点诊断

| 命令 | 说明 |
|---|---|
| `/cc status` | 查看当前扫描预算、TPS、调度器状态与各模块启用情况 |
| `/cc hotspots` | 查看服务器当前的实体密集热点区块列表 |
| `/cc doctor` | 全面检查所有配置文件与菜单规则的健康度与报错项 |
| `/cc validate` | 校验当前配置文件的语法有效性 |

### 管理菜单与配置管理

| 命令 | 说明 |
|---|---|
| `/cc menu` | 打开可视化 GUI 管理面板，可在游戏内调整规则与菜单 |
| `/cc reload` | 自动保存当前配置快照后，热重载所有配置、语言和菜单文件 |
| `/cc lang <zh_cn\|en_us\|auto>` | 切换插件的提示语言 |
| `/cc snapshot [名称]` | 手动为当前配置文件创建快照备份 |
| `/cc history [玩家] [页码]` | 查看虚空垃圾桶领取记录 |

### 区域巡查与传送

| 命令 | 说明 |
|---|---|
| `/cc tp <世界\|back> [x] [y] [z]` | 传送至热点区块或指定坐标进行现场排查 |
| `/cc back` | 返回执行巡查传送前的原位置 |

---

## 权限节点清单

| 权限节点 | 用途说明 | 默认赋予 |
|---|---|---|
| `cyuclear.use` | 基础使用权限，允许打开虚空垃圾桶与查看玩家帮助 | 全体玩家 |
| `cyuclear.bin.deposit` | 允许向个人投放缓冲区或虚空垃圾桶手动丢入闲置物品 | 全体玩家 |
| `cyuclear.admin` | 管理员权限，允许使用清理、预演、检查、恢复、菜单与重载等全部命令 | OP |
