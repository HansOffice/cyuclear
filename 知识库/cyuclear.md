# CyuClear 知识库总览

- **当前版本**：1.4.5（Kotlin 编写；Paper / Folia 运行包支持现代服务端，Legacy 运行包面向 1.8~1.12 旧端；三端只选一个放入 plugins）
- **jar 区分**：`cyuclear-paper-1.4.5.jar` 用于 Paper / Purpur 1.13+；`cyuclear-folia-1.4.5.jar` 用于 Folia；`cyuclear-legacy-1.4.5.jar` 用于 1.8~1.12 Spigot 系旧端
- **主命令**：`/cyuclear`，别名 `/cc`
- **定位**：轻量周期清理 + 区块实体限流 + 虚空垃圾桶回收 + Panic 熔断保护 + 跨服同步 + 误删恢复中心

CyuClear 解决服务器掉落物与生物堆积造成的卡顿，通过智能分批扫描与预算控制，在不让玩家感到掉帧的前提下清理多余实体。它提供六大核心支柱：**平滑清理**（掉落物与实体按黑白名单分批扫除）、**高价值保护**（贵重物品与自定义物品安全放行）、**区块限流**（抑制密集实体与高频出生）、**虚空垃圾桶**（被清理的物品进入公共桶供玩家拾回）、**Panic 熔断**（TPS 骤降时自动削减生怪）、**恢复中心**（记录每次清理批次，误清理可一键恢复）。

- 清理采用自适应时间片预算（默认 600 区块/tick、15ms/tick 预算），杜绝全服瞬间冻结
- 支持候选活跃区块索引，优先检测有玩家活动与生怪频繁的热点区域
- 虚空垃圾桶支持玩家随时取回被清理物品，支持潜影盒等容器快照完整校验
- 每次清理均保存批次快照，服主可通过 `/cc runs` 查看明细，通过 `/cc recover` 撤销清理
- 支持对接 PlaceholderAPI、MythicMobs、CraftEngine 与各类实体堆叠插件

## 1.4.5 的要点

- 全新安装默认总开关 `enabled: false`，先核对规则与预演再开服启用，避免服主误删已有物品
- 智能启发式免死保护（默认开启）：自动识别交易成熟村民、工位工作村民、刷铁机核心与动力运输矿车，零配置保护玩家装置
- 原生 Prometheus 监控指标导出（`/metrics`）：零额外依赖，实时导出清理速率、热点熔断与微秒级耗时监控
- 菜单交互动线全面升级，物理交互型界面完全放行玩家自由整理背包，不再冻结玩家自身物品
- 智能 Tab 补全首字符分流，键入英文精准给出指令，未输入或输入中文给出纯净中文说明
- 标配 zh_cn 与 en_us 双语语言体系，全配置注释规范化并提供首例教学母版

## 一分钟上手

1. 按照服务端类型选择对应的单个 jar 文件放入 `plugins/` 目录，启动服务器生成默认配置
2. 在 `rules.yml` 中根据服务器玩法调整掉落物和实体清理名单；拿着物品输入 `/cc check` 即可现场查看清理判定
3. 输入 `/cc preview` 预演一次清理，查看预计被清理的数量与类型，确认无误
4. 打开 `config.yml`，把 `enabled: false` 改为 `enabled: true`，输入 `/cc reload` 生效并启动自动清理
5. 玩家可通过 `/cc bin` 打开虚空垃圾桶翻找刚被清理的掉落物

## 配置文件清单

数据与配置文件均位于 `plugins/cyuclear/` 下：

| 文件 / 目录 | 内容说明 |
|---|---|
| `config.yml` | 总开关、清理周期、倒计时提示、性能档位与候选区块索引 |
| `rules.yml` | 掉落物名单、实体名单、实时拦截与区块硬限制规则 |
| `areas.yml` | 独立世界与坐标区域的专属清理与保护规则 |
| `storage.yml` | Redis 或 MySQL 跨服同步连接配置 |
| `void-bin.yml` | 虚空垃圾桶容量、开放倒计时、入桶白名单与个人投放缓冲区 |
| `sounds.yml` | 清理倒计时、垃圾桶开启、警报音效 |
| `lang/` | 双语语言文件目录（`zh_cn.yml` / `en_us.yml`） |
| `menu/` | 10 个字符布局 GUI 菜单文件（垃圾桶、管理面板、规则编辑、热点查看等） |
| `snapshots/` | 配置快照与历史备份目录 |
| `recovery/` | 清理批次数据与撤销恢复记录 |
