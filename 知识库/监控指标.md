# Prometheus 与 Grafana 监控对接

CyuClear 内置基于 JDK 标准原生组件的轻量指标导出端点，无需额外依赖即可输出标准 OpenMetrics / Prometheus 纯文本格式监控指标。

## 1. 开启监控端点

在 `config.yml` 中开启指标服务：

```yaml
metrics:
  # 是否开启 Prometheus 监控指标 HTTP 导出端点 (/metrics)
  enabled: true
  # 监控端点 HTTP 监听端口 (默认 9527)
  port: 9527
```

保存后执行 `/cc reload` 即可启动指标端点。通过浏览器或命令行直接访问：

```bash
curl http://127.0.0.1:9527/metrics
```

## 2. Prometheus 抓取配置 (prometheus.yml)

在 Prometheus 配置文件的 `scrape_configs` 中新增抓取任务：

```yaml
scrape_configs:
  - job_name: "cyuclear"
    scrape_interval: 10s
    static_configs:
      - targets: ["127.0.0.1:9527"]
        labels:
          server: "survival-01"
```

## 3. 指标清单速查

| 指标名称 | 类型 | 说明 |
|---|---|---|
| `cyuclear_build_info` | Gauge | 插件版本与服务端平台元数据标签 |
| `cyuclear_scanned_chunks_total` | Counter | 累计扫描区块总数 |
| `cyuclear_scanned_entities_total` | Counter | 累计扫描实体总数 |
| `cyuclear_cleaned_items_total` | Counter | 累计清理掉落物总数 |
| `cyuclear_cleaned_entities_total` | Counter | 累计清理实体总数 |
| `cyuclear_last_cleanup_duration_millis` | Gauge | 上次清理总耗时（毫秒） |
| `cyuclear_last_cleanup_duration_micros` | Gauge | 上次清理总耗时（微秒） |
| `cyuclear_last_cleanup_timestamp_seconds` | Gauge | 上次清理完成时的 Unix 秒级时间戳 |
| `cyuclear_last_cleaned_items` | Gauge | 上次清理扫除的掉落物数量 |
| `cyuclear_last_cleaned_entities` | Gauge | 上次清理扫除的实体数量 |
| `cyuclear_last_scanned_entities` | Gauge | 上次清理遍历的实体总数 |
| `cyuclear_last_processed_chunks` | Gauge | 上次清理实际处理的区块总数 |
| `cyuclear_last_slowest_chunk_millis` | Gauge | 上次清理中最慢单区块处理耗时（毫秒） |
| `cyuclear_last_slowest_chunk_micros` | Gauge | 上次清理中最慢单区块处理耗时（微秒） |
| `cyuclear_hotspots_active_total` | Gauge | 全服当前活跃的高负载热点区块总数 |
| `cyuclear_hotspots_breaker_total` | Gauge | 全服当前处于熔断拦截状态的超载区块总数 |
| `cyuclear_void_bin_items_total` | Gauge | 虚空垃圾桶当前暂存的物品总件数 |
| `cyuclear_void_bin_types_total` | Gauge | 虚空垃圾桶当前暂存的物品种类数 |
| `cyuclear_candidate_chunks_total` | Gauge | 当前候选索引池中的活跃区块数量 |
| `cyuclear_cleanup_running` | Gauge | 当前是否正处于分批清理扫描流程中（1 代表是，0 代表否） |

## 4. 常用 PromQL 监控大盘看板表达式

### 清理吞吐与速率
- **每秒清理掉落物速率**：
  ```promql
  rate(cyuclear_cleaned_items_total[1m])
  ```
- **每秒清理实体速率**：
  ```promql
  rate(cyuclear_cleaned_entities_total[1m])
  ```
- **每分钟扫描区块吞吐**：
  ```promql
  increase(cyuclear_scanned_chunks_total[1m])
  ```

### 负载与熔断告警
- **超载熔断告警触发**：
  ```promql
  cyuclear_hotspots_breaker_total > 0
  ```
- **活跃热点区块堆积监控**：
  ```promql
  cyuclear_hotspots_active_total
  ```

### 单次扫描耗时与抖动
- **最近一次扫描耗时（秒）**：
  ```promql
  cyuclear_last_cleanup_duration_millis / 1000
  ```
- **最慢区块单格处理时间（毫秒）**：
  ```promql
  cyuclear_last_slowest_chunk_millis
  ```
