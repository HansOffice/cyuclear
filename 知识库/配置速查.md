# CyuClear 配置速查

## 1. 主配置 config.yml

| 配置路径 | 默认值 | 作用说明 |
|---|---|---|
| `enabled` | `false` | 总开关。全新安装默认关闭，配置好规则并确认无误后改为 `true` |
| `language` | `"zh_cn"` | 提示语言：`zh_cn`（简体中文）或 `en_us`（English） |
| `cleanup.interval-seconds` | `600` | 自动清理循环间隔时间（秒） |
| `cleanup.warning-times` | `[60, 30, 10, 3]` | 清理前触发倒计时提示的秒数节点 |
| `cleanup.warning-output.chat` | `true` | 是否在聊天栏广播清理倒计时与完成提示 |
| `cleanup.warning-output.actionbar` | `false` | 是否在快捷栏（ActionBar）显示倒计时 |
| `cleanup.warning-output.bossbar` | `false` | 是否使用顶部 BossBar 显示清理倒计时血条 |
| `performance.profile` | `"快速"` | 清理性能预设档位：`保守` / `均衡` / `快速` / `极限` |
| `performance.scan.max-chunks-per-tick` | `600` | 每 tick 扫描的最大区块数量上限 |
| `performance.scan.max-millis-per-tick` | `15` | 每 tick 清理扫描允许占用的最高毫秒预算，超时立即让出主线程 |
| `performance.candidate-index.enabled` | `true` | 启用活跃区块候选索引，优先扫描玩家密集与频繁活动的区块 |
| `recovery.enabled` | `true` | 是否开启批次记录与误删恢复中心 |
| `recovery.max-history-runs` | `50` | 内存与磁盘中保留的最近清理批次数 |
| `metrics.enabled` | `false` | 是否开启 Prometheus 监控指标 HTTP 导出端点 |
| `metrics.port` | `9527` | 监控指标 HTTP 导出端点监听端口 |

## 2. 规则配置 rules.yml

### 掉落物规则 (`targets.items`)

| 配置路径 | 默认值 | 作用说明 |
|---|---|---|
| `enabled` | `true` | 掉落物清理总开关 |
| `mode` | `"黑名单"` | 名单模式：`黑名单`（名单内保留）、`白名单`（名单内清理）、`并行名单` |
| `grace.minimum-age-seconds` | `10` | 普通掉落物保护时间（秒），刚掉落未达该时长的物品不会被清理 |
| `grace.high-value-minimum-age-seconds` | `60` | 高价值物品（如下界合金、下界之星）延长保护时间（秒） |
| `keep-list.match-mode` | `"精确"` | 匹配模式：`精确`、`通配` 或 `正则` |
| `keep-list.list` | 包含钻石、鞘翅等 | 保留物品 ID 列表，前缀可写 `通配:` 或 `正则:` |

### 实体规则 (`targets.entities`)

| 配置路径 | 默认值 | 作用说明 |
|---|---|---|
| `enabled` | `true` | 实体清理总开关 |
| `mode` | `"黑名单"` | 名单模式：`黑名单`（保留）、`白名单`（清理） |
| `keep-list.list` | 包含展示框、盔甲架等 | 免于清理的实体类型列表 |
| `age-rules.minimum-age-ticks` | `600` | 刚生成的实体最低存活时间（tick），未达到时不清理 |
| `name-rules.require-custom-name` | `true` | 玩家命名过的命名牌生物默认不予清理 |

### 启发式免死保护 (`targets.entities.heuristics`)

| 配置路径 | 默认值 | 作用说明 |
|---|---|---|
| `enabled` | `true` | 智能启发式免死保护总开关 |
| `traded-villager` | `true` | 交易成熟村民保护（玩家交易过或有交易经验的村民免于被清） |
| `workstation-villager` | `true` | 工位村民保护（村民交易所内拥有职业方块且空间被限位的村民免于被清） |
| `iron-farm-villager` | `true` | 刷铁机核心识别（聚集且处于恐慌状态或周围有床与恐吓生物的村民组合保护） |
| `powered-vehicle` | `true` | 动力运输载具保护（位于激活动力铁轨或探测铁轨上的运输矿车免于被清） |
| `cache-seconds` | `60` | 启发式判定内存缓存有效期（秒），实现高频 O(1) 避让 |

### 区块实体限制 (`limits.chunk.entities`)

| 配置路径 | 默认值 | 作用说明 |
|---|---|---|
| `mode` | `"SAFE"` | 限制模式：`OFF`（关闭）、`SAFE`（安全模式）、`STRICT`（严格模式） |
| `max-per-chunk` | `100` | 单个区块内允许的实体总量上限，超出时拒绝新生实体 |

### Panic 紧急熔断 (`panic`)

| 配置路径 | 默认值 | 作用说明 |
|---|---|---|
| `enabled` | `true` | 是否开启 TPS 急剧下滑时的紧急熔断保护 |
| `min-tps` | `14.0` | 触发熔断保护的最低 TPS 阈值 |
| `max-entities-per-chunk` | `50` | 熔断生效期间单区块实体数量硬限制 |

## 3. 虚空垃圾桶配置 void-bin.yml

| 配置路径 | 默认值 | 作用说明 |
|---|---|---|
| `void-bin.enabled` | `true` | 是否启用虚空垃圾桶回收机制 |
| `void-bin.always-open` | `false` | 是否允许玩家在无清理时也随时输入 `/cc bin` 打开垃圾桶 |
| `void-bin.stacked-mode` | `false` | 垃圾桶界面内相同物品是否自动合并为一组显示 |
| `void-bin.expire-seconds` | `60` | 清理后垃圾桶保持开放的有效秒数，倒计时结束后清空 |
| `void-bin.deposit-buffer.enabled` | `true` | 是否开启个人手动投放缓冲区 |

## 4. 菜单与动作语法 (`menu/`)

`menu/` 目录下默认包含 10 个界面配置文件。按钮支持原版材质、`ia:` / `ce:` 外部物品及头颅纹理

### 按钮动作格式 (`actions`)

```yaml
actions:
  - "[default]"                # 执行按钮默认内置逻辑
  - "[open] bin"               # 打开指定菜单（bin/admin/rules/runs/hotspots 等）
  - "[message] 文本"           # 发送聊天消息
  - "[actionbar] 文本"         # 发送快捷栏提示
  - "[sound] ENTITY_EXPERIENCE_ORB_PICKUP 1.0 1.0" # 播放音效
  - "[player] 指令"            # 以玩家身份执行命令
  - "[console] 指令"           # 以控制台身份执行命令
  - "[close]"                  # 关闭当前菜单
  - "[refresh]"                # 刷新当前界面
```

## 5. PlaceholderAPI 变量大全

| 占位符 | 输出说明 |
|---|---|
| `%cyuclear_enabled%` | 总开关是否开启（true / false） |
| `%cyuclear_active%` | 清理任务是否处于激活运行状态 |
| `%cyuclear_interval_seconds%` | 自动清理循环周期（秒） |
| `%cyuclear_countdown%` | 距离下次清理剩余秒数 |
| `%cyuclear_countdown_text%` | 距离下次清理剩余时间（格式化） |
| `%cyuclear_is_running%` | 当前是否正在执行分批扫描清理 |
| `%cyuclear_run_id%` | 最近或当前清理批次编号 |
| `%cyuclear_last_items%` | 上次清理掉落物数量 |
| `%cyuclear_last_entities%` | 上次清理实体数量 |
| `%cyuclear_last_total%` | 上次清理总量 |
| `%cyuclear_last_time%` | 上次清理总耗时（毫秒） |
| `%cyuclear_bin_enabled%` | 虚空垃圾桶是否启用 |
| `%cyuclear_bin_open%` | 虚空垃圾桶当前是否开放拾回 |
| `%cyuclear_bin_countdown%` | 虚空垃圾桶剩余开放秒数 |
| `%cyuclear_chunk_x%` | 玩家当前所在区块 X 坐标 |
| `%cyuclear_chunk_z%` | 玩家当前所在区块 Z 坐标 |
| `%cyuclear_chunk_is_hotspot%` | 当前脚下区块是否为实体聚集热点 |
| `%cyuclear_hotspots_total%` | 全服当前活跃热点区块总数 |
| `%cyuclear_heuristics_enabled%` | 启发式免死保护总开关状态（true / false） |
| `%cyuclear_metrics_enabled%` | 监控指标导出端点是否启用（true / false） |
| `%cyuclear_metrics_port%` | 监控指标导出端点监听端口 |
| `%cyuclear_platform%` | 当前运行包平台（paper / folia / legacy） |
| `%cyuclear_version%` | 插件当前版本 |
